# Explanation
What we did was transform the trailer for an action video game and some suspenseful elements into an absurd and comical trailer.

We searched the internet for a compilation of videos with this particular “humor” and tried to make the actions in each scene match the tone of the audio we were integrating.
We gave it meaning based on what we found funny at the time and some “memes” that we used as references in our everyday conversations.
